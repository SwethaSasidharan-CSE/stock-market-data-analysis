# Stock Market Data Analysis and Visualization

## Project Overview

This project focuses on extracting, analysing and visualising historical stock market data and company revenue for Tesla and GameStop using Python.

The project uses data extraction, web scraping and data visualisation techniques to explore stock price and revenue trends.

## Technologies Used

- Python
- Pandas
- yfinance
- BeautifulSoup
- Requests
- Matplotlib


## Project Objectives

- Retrieve historical stock market data for Tesla and GameStop.
- Extract company revenue information through web scraping.
- Clean and organise the extracted data for analysis.
- Visualize stock prices and revenue trends using graphs.

## Implementation

### 1. Stock Data Extraction
Used the yfinance library to retrieve historical stock price data for Tesla and GameStop.

### 2. Web Scraping
Used Requests and BeautifulSoup to extract historical revenue information from web pages.

### 3. Data Cleaning
Used Pandas to process, clean and organise the extracted revenue data.

### 4. Data Visualization
Used Matplotlib to create graphs comparing historical stock prices and company revenue.

## Project Files

- `stock_market_data_analysis.ipynb` – Jupyter Notebook containing the Python code, data extraction, analysis and visualizations.

## How to Run

1. Clone this repository.
2. Open the notebook using Google Colab or Jupyter Notebook.
3. Install the required Python libraries if needed:

```bash
pip install yfinance pandas requests beautifulsoup4 matplotlib
```

4. Execute the notebook cells sequentially.
5. Review the generated stock price and revenue visualizations.
